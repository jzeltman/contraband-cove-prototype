# Confirmed prototype decisions

## Judgment rewards

Confirmed by the owner: an incorrect CLEAR or HOLD verdict earns **zero shipment income** and **never deducts existing coins**. Correct judgments earn the configured shipment reward. There is no guaranteed base wage, fine or debt from an incorrect judgment.

Other prototype scope is tracked in [roadmap issue #1](https://github.com/jzeltman/contraband-cove-prototype/issues/1). This file records the latest reward clarification; it is not a replacement for the GDD.
